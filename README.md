# YouTube Video Search App

A simple Vue.js application that allows users to search for YouTube videos using the YouTube Data API.

## Project Setup

```
npm install
```

### Compile and Hot-Reload for Development

```
npm run serve
```

### Compile and Minify for Production

```
npm run build
```

## Features

- Search for YouTube videos
- View video thumbnails, titles, and descriptions
- Watch videos directly on YouTube via links
- Responsive design
